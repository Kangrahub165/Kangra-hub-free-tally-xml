HOW TO RUN THE APPLICATION LOCALLY:

1. START EVERYTHING:
   Double-click "start_all.bat".
   This will:
   - Start the FastAPI Backend on http://localhost:8000
   - Start the Next.js Frontend on http://localhost:3000
   - Automatically open your default web browser to http://localhost:3000

2. START ONLY BACKEND:
   Double-click "start_backend.bat" (Port 8000).

3. START ONLY FRONTEND:
   Double-click "start_frontend.bat" (Port 3000).

4. RESTART ALL SERVERS:
   Double-click "restart_all.bat".

5. STOP ALL SERVERS:
   Double-click "stop_all.bat" to terminate any servers running on ports 8000 and 3000.

===============================================================================
